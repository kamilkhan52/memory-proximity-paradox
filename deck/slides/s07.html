07 · Deployed vs ambitious

The deployed forms need no new programming model; the ambitious forms remain niche.

Split each direction in two: proximity vs compute at memory (A); cheaper, extended or shared GB, on one host or across hosts (B).

Pattern: ambitious forms find use only inside vendor-controlled stacks (PIM demos) or on bulk, predictable data (KV pools). The critiques mirror each other: A2 is limited by process, heat and capacity; B2 by latency and switch cost.
