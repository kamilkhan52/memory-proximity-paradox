02 · Distance is a proxy

Distance is a proxy: closer is not lower‑latency, and farther costs hops, not metres.

A 6 ft (~2 m) cable adds ~12 ns each way. Latency lives in device timing, controllers, SerDes, switches and queues.

Measured idle latency (filled) vs spec or modelled estimates (hollow). Platforms differ; compare within a row. NVMe is a typical value. Grace and GPU rows are [S] approximations, confounded by each host's cache hierarchy.

Closer ≠ faster. On Xeon Max, the same cores see ~20% higher pointer-chase latency from HBM2e than from DDR5, yet stream ~700 vs ~200 GB/s.
Farther = hops. One CXL hop adds ~100–280 ns (measured); a switch adds ≥220 ns moreV.
"Far" is a role. GB200's capacity tier (LPDDR5X) sits beside the Grace CPU, not out on a far network.
